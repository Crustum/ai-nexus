# CakePHP AiNexus Plugin

The **AiNexus** plugin provides a browser dev dashboard for interacting with AI agents from CakePHP applications.

Use it to discover agents, chat with them in a playground with streaming and tool inspection, and browse conversation history through HTTP controllers, a Vue 3 frontend, and console commands for pruning stored conversations.

## Requirements

* PHP 8.4+
* crustum/cakephp-ai

See [Versions.md](docs/Versions.md) for the supported CakePHP versions.
